Core components of the sharded cluster:

1. shard----stores a subset of the data, ideally configured as a replica set.
	commonly called shard replica.
	In a single cluster, there will be multiple shard replicas.

2. mongos(query router)----routes the queries from the applications to the appropriate shard.
3. config servers----------store metadata and configuration settings---ie which data is available in which replica is stored within config servers. Typically implemented as a replica.


Sharding is also called Partitioning.

Assume that there are 10 rows in a table with _id ranging from 1 to 10 and there are 3 replica sets.

steps:

1. Terminate any mongod or mongosh instances if they are running.

2. create the data and log directories of config replica
	
student@ubuntu:~$ sudo mkdir -p /var/lib/conf-svr-1-data
student@ubuntu:~$ sudo mkdir -p /var/lib/conf-svr-2-data
student@ubuntu:~$ sudo mkdir -p /var/log/conf-svr-1
student@ubuntu:~$ sudo mkdir -p /var/log/conf-svr-2

3. start the servers of config replica

student@ubuntu:~$ sudo mongod --configsvr --dbpath /var/lib/conf-svr-1-data/ --logpath /var/log/conf-svr-1/mondod.log --port 27017 --replSet config-replica
student@ubuntu:~$ sudo mongod --configsvr --dbpath /var/lib/conf-svr-2-data/ --logpath /var/log/conf-svr-2/mondod.log --port 27018 --replSet config-replica

4. start a mongoshell for config-svr-1 and initialize the replica

Mongodb Atlas:

Mongodb Atlas is a fully mangaged, cloud based database service(DBaaS----Database as a Service) for mongodb.

Instead of installing, configuring and managing mongodb on your own servers, Atlas allows you to deploy and scale databases within few clicks.

organization is the highest level container in mogodb atlas.
It is normally used to represent a company, team or business unit.

Project:

A project is a logical workspace in an organization.
A project contains the mongodb resources for that environment.


A project can contain cluster, database users, ip access list, network configuration and etc.

atlas cli-----atlas can be managed from the command line.
